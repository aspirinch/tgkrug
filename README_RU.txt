КРУГ — бот-компаньон для Telegram-групп
=====================================
Самостоятельный проект в жанре чат-ботов-компаньонов. Не официальный Iris,
не использует его код, название или оформление. Все данные — локальная SQLite.
Это исходники для самостоятельного запуска, а не уже размещённый онлайн-бот.

1. СОЗДАЙТЕ TELEGRAM-БОТА
Откройте настоящего @BotFather в Telegram, отправьте /newbot и следуйте инструкции.
Создайте имя и уникальный username, заканчивающийся на bot. Скопируйте токен.
Токен нельзя отправлять в чат, публиковать или помещать в открытый репозиторий.
При утечке перевыпустите его через @BotFather.

2. ЗАПУСК НА WINDOWS
Нужен установленный Python 3.12 (64-bit). Проект ориентирован на эту версию.
Распакуйте ZIP в отдельную папку. Не запускайте файлы прямо из архива.
В Проводнике включите отображение расширений файлов.
Скопируйте .env.example в .env. В .env замените значение BOT_TOKEN своим токеном.
Итоговый файл должен называться .env, а не .env.txt.
Откройте PowerShell в распакованной папке и выполните:

py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe bot.py

Либо после установки Python 3.12 дважды нажмите start_windows.bat.
BAT создаёт .venv312, устанавливает зависимости только при первом запуске,
проверяет .env и запускает бота. Другие версии Python не удаляйте.
Если запускаете ручными командами, используйте .venv; если BAT — .venv312.
Активация окружения и Visual Studio не требуются.
Остановка: Ctrl+C. Пока компьютер спит или процесс остановлен, бот не отвечает.
Для круглосуточной работы нужен постоянно включённый компьютер или сервер.
Запускайте только ОДИН экземпляр с одним токеном (long polling).

Linux/macOS с Python 3.12:
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python bot.py

3. ПОДКЛЮЧЕНИЕ К ЧАТУ
Откройте бота, отправьте /start, нажмите «Добавить в группу».
Или добавьте его через настройки участников группы.
Для /ban, /mute, /kick назначьте администратором с правом блокировки участников.
Мут работает только в супергруппах. Чтение профилей и РП не требует модераторских прав.
Владельцы и администраторы защищены от команд модерации этого бота.
Административные команды надо отправлять от своего аккаунта, не анонимно.

Для русских команд без слеша и опыта за обычные сообщения:
@BotFather -> /setprivacy -> выберите вашего бота -> Disable.
Если Telegram не применил настройку, удалите бота из группы и добавьте снова.
Бот-администратор обычно получает все сообщения и без отключения privacy.
При включённой приватности обычные сообщения могут быть недоступны:
используйте адресованные slash-команды, например /hug@username_бота.
Не запускайте одновременно webhook и этот polling-бот.

4. КОМАНДЫ
РП, строго ответом на сообщение человека:
/hug — обнять; /pat — погладить; /handshake — пожать руку;
/highfive — дать пять; /tea — дать чай; /cookie — дать печенье;
/flower — подарить цветок; /support — поддержать;
/poke — тыкнуть; /bonk — шуточный удар мягкой подушкой.
Русские варианты — точные фразы справа, тоже ответом.
Для /bonk русская команда: стукнуть.
РП-сценарии доступны только между разными людьми; не на каналы и ботов.
В чате /rp_off отключает действия в ваш адрес, /rp_on возвращает согласие.

/profile — собственный профиль или чужой ответом; /top — топ-10.
За обычный текст: 5 XP не чаще раза в минуту на человека в чате.
Команды и точные РП-фразы XP не начисляют. Каждые 100 XP — новый уровень.
/rep — ответом +1 репутация: одному человеку от вас раз в сутки (UTC).
Самому себе ставить репутацию нельзя; разным людям в тот же день можно.
/coin, /dice — монетка и кубик.
/rules — правила; /help — справка; /privacy — данные бота.

Админам:
/settings
/rp on или off
/welcome on или off
/setwelcome Привет, {name}! Добро пожаловать в {chat}. Правила: /rules
/setrules 1. Уважайте участников. 2. Не спамьте.
/warn причина — ответом, записать предупреждение
/warnings — ответом, количество предупреждений
/unwarn — ответом, сбросить все предупреждения
/mute 10 причина — ответом, запретить писать на 10 минут (1–10080)
/unmute — ответом, восстановить общие разрешения группы
/ban причина — ответом, заблокировать
/unban — ответом на старое сообщение, снять блокировку
/kick причина — ответом, удалить с возможностью вернуться
У пользователя-администратора тоже должно быть право ограничивать участников.
Предупреждения НЕ ведут к автоматическому бану. Это сделано намеренно.
/mute не заменяет уже существующие индивидуальные ограничения.
/unmute восстанавливает разрешения группы, а не прежние личные ограничения.
Telegram может удалять сообщения при бане в супергруппе независимо от параметра
revoke_messages; учитывайте это до использования /ban и /kick.

5. ДАННЫЕ И ОГРАНИЧЕНИЯ
База: data/krug.sqlite3 и служебные -wal/-shm файлы SQLite при работе.
Сохраняются ID чатов и участников, имена, XP, репутация, предупреждения,
согласие на РП и настройки. Содержание переписки в базу не записывается.
Статистика не сбрасывается при перезапуске; каждый чат изолирован.
При преобразовании группы в супергруппу данные переносятся при получении
служебного события Telegram. Не удаляйте базу, чтобы не потерять статистику.
Для резервной копии остановите бота и скопируйте папку data.
Удаление базы при остановленном боте сбросит ВСЕ чаты, не один профиль.
Индивидуального интерфейса удаления данных пока нет: запрос оператору.
РП-согласие не является согласием на хранение данных: предупредите участников
об обработке ID и статистики, прежде чем запускать бота в своём сообществе.

Есть ограничение команд/РП: один вызов пользователя раз в две секунды.
Более частые вызовы молча игнорируются. Это не антиспам-модератор чата.
Нет экономики, платежей, зеркал, веб-панели, автоочистки спама или хостинга.
Нет доступа к истории до добавления, перепискам других ботов и пользователям,
чьи сообщения Telegram не передаёт. ID чатов и пользователей не секретны,
но базу с профилями нельзя публиковать.

6. ПРОВЕРКА
Статически проверены синтаксис Python и основные операции базы SQLite:
изоляция чатов, XP-cooldown, репутация, настройки, предупреждения и РП-согласие.
В архив включён test_store.py: запуск python test_store.py после установки зависимостей.
Реальные запросы Telegram не проверялись: нужен ваш токен и тестовая группа.
Сначала проверяйте административные команды в отдельной тестовой супергруппе.

Если не запускается:
— «py не найден»: установите Python и Python Launcher.
— Unauthorized/InvalidToken: проверьте токен в .env.
— Conflict: остановите второй экземпляр бота, включая хостинги.
— Не отвечает на «обнять»: проверьте privacy, ответ на сообщение и /rp on.
— Не мутит: нужна супергруппа и права ограничения участников у вас и у бота.
— После команд быстро нет ответа: выждите минимум две секунды.
